## Introduction

Building a blog that's both developer-friendly and performant can be challenging. In this post, I'll walk through how I built this blog using **Next.js 16**, **Velite** for type-safe content management, and **MDX** for rich content authoring.

## Why Velite?

Velite is a content layer that brings type safety to your content. Unlike traditional CMS solutions, Velite:

- **Validates content at build time** - Catch missing fields before deployment
- **Generates TypeScript types** - Full autocomplete for your content
- **Supports MDX** - Write React components in your markdown

Here's an example of the schema I use:

```typescript
const posts = defineCollection({
  name: 'Post',
  pattern: 'blog/**/*.mdx',
  schema: s.object({
    title: s.string().max(100),
    description: s.string().max(300),
    publishedAt: s.isodate(),
    tags: s.array(s.string()),
    difficulty: s.enum(['beginner', 'intermediate', 'advanced']),
  }),
});
```

## Key Features

### 1. Type-Safe Content

Every blog post is validated against a schema. Missing a required field? The build fails with a helpful error message.

### 2. Automatic SEO

Each post generates:
- Open Graph meta tags
- Twitter Card tags
- JSON-LD structured data
- Sitemap entries

### 3. Performance

- Static generation at build time
- Optimized images with Next.js Image
- Minimal JavaScript

> "The best blog is one that loads fast and ranks well. Everything else is secondary."

## Code Example

Here's how the blog fetches posts:

```typescript
import { posts } from '#site/content';

export function getPublishedPosts(): Post[] {
  return posts
    .filter((post) => !post.draft)
    .sort((a, b) =>
      new Date(b.publishedAt).getTime() -
      new Date(a.publishedAt).getTime()
    );
}
```
